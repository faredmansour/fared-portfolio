# Fared Mansour — DevOps & Full Stack Portfolio

Personal portfolio for **Fared Mansour**, focused on AWS, Terraform, Docker, CI/CD, backend engineering and full-stack applications.

## Featured work

- **DevOps Control Center** — React/TypeScript + Django/DRF + FastAPI Test App + AWS ECS/Fargate + Terraform + ECR + ALB + VPC + RDS + Redis + CloudWatch. Includes SSRF defenses, host allowlisting, bounded execution and automated verification.
- **EduCommunity Egypt** — React/Vite + Node/Express + MongoDB + Redis + Socket.IO + JWT refresh tokens + Docker + AWS ECS/Fargate + Terraform + S3/CloudFront. Portfolio repository is being prepared for the final upgraded version.
- **E-Commerce Platform** — React/Vite + Node/Express + MongoDB + Redis + Docker Compose + JWT + Stripe + Swagger/OpenAPI + Jest + GitHub Actions.
- **AI-Based Full-Stack Capstone** — Digital Pioneers Initiative project combining React, Node/Express, MongoDB, AI-oriented automation and Docker/cloud deployment practice.
- **Cloud-Native EKS Lab** — planned/in-progress extension into AWS EKS, Kubernetes and observability.

## Tech focus

**Cloud:** AWS, ECS/Fargate, ECR, ALB, VPC, RDS, ElastiCache/Redis, S3, CloudFront, IAM, CloudWatch

**DevOps:** Terraform, Docker, GitHub Actions, Jenkins, CI/CD, Trivy, Linux, Bash

**Backend:** Node.js, Express, Python, Django/DRF, FastAPI, REST APIs

**Frontend:** React, Vite, JavaScript/TypeScript, Tailwind CSS

**Data:** MongoDB, PostgreSQL/SQL, Redis
